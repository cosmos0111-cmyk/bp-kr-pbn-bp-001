## 구조

### cold-open-case
클라우드 엣지케이스로 시작하여, 서버 리소스 관리에 대한 간단한 실수부터 시작한다.

## 주제 분석

### 구체적 장면으로 시작해 원인을 뒷전으로 공개
#### 반대 의견도 탐색하자
AWS Lightsail 인스턴스에서 CPU 크레딧이 소진될 때, 커널 패닉이 발생하는 것은 매우 일반적인 현상이다. 이는 AWS 서비스의 기본 동작 때문이며, 특정 AMI 조합으로 인해 더욱 심각하게 나타난다.

### 독자의 선택을 질문
독자가 가장 흔히 하는 선택은 바로 "Amazon Linux 2"와 "Ubuntu 18.04 LTS"를 선택하는 경우이다. 이 두 AMIs는 CPU 리소스가 더 많이 사용되는 특성을 가지고 있어, 이를 예측하고 대비해야 한다.

#### 체크리스트
- **AMI Choice:** Amazon Linux 2 또는 Ubuntu 18.04 LTS 선택
- **CPU Usage:** 고도의 작업을 수행할 때 CPU 사용량 확인
- **Event Code:** 오류 코드 확인

### 근거 방식
반대 의견이 타당한 조건도 함께 인정한다. 예를 들어, S3 버저닝 비용 폭증은 AWS Lightsail 인스턴스에 대한 트래픽 패턴의 문제로 인해 발생할 수 있다. 이는 클라우드 서비스 사용 전 적절히 검토해야 할 중요한 요소이다.

### 정답 대신 조건별 선택 기준으로 마무리
결론적으로, CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 AMI 조합은 "Amazon Linux 2"와 "Ubuntu 18.04 LTS"일 확률이 높다. 이 두 AMIs가 사용될 때는 반드시 고도의 작업을 수행할 때 CPU 사용량과 오류 코드를 체크해야 한다.
